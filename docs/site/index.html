DesktopSubsystem

For Android™

DSA는 Android를 전용 가상 머신에서 통째로 실행하고, 앱 화면 하나하나를 PC의 진짜 창으로 띄웁니다. 작업 표시줄, 알림, 키보드 입력, 파일 끌어 놓기가 다른 데스크톱 앱과 똑같이 동작합니다.

DSA runs the whole of Android in a dedicated virtual machine and shows each app as a real window on your PC. The taskbar, notifications, keyboard input and file drag and drop work the way they do for any other desktop app.

설치 프로그램 받기Get the installer 작동 방식How it works

Android는 온전하게,
경계는 HAL에서

Android stays whole.
The boundary is the HAL.

커널, ART, 프레임워크는 전용 VM 안에 그대로 두고, 화면과 장치만 PC로 옮깁니다.

The kernel, ART and the framework stay inside a dedicated VM. Only the display and the devices move to your PC.

앱 하나, 창 하나

One app, one window

작업마다 자기 아이콘과 이름을 가진 창이 생깁니다. 스냅, Alt+Tab, 작업 표시줄이 그대로 동작합니다.

Every task gets its own window with its own icon and name. Snap, Alt+Tab and the taskbar just work.

  • 통합 제목 표시줄Integrated title bar
  • 스냅 레이아웃Snap layouts
  • 시작 메뉴와 작업 표시줄Start menu and taskbar

그리기는 PC의 GPU가

Your GPU does the drawing

앱의 OpenGL ES와 Vulkan 명령을 PC의 GPU가 실행하고, 렌더러는 따로 떨어진 프로세스에서 돕니다.

Your PC's GPU runs each app's OpenGL ES and Vulkan, and the renderer lives in a process of its own.

  • ANGLE
  • Vulkan 원격 실행Vulkan remoting
  • GPU 리셋 복구GPU reset recovery

쓰지 않는 메모리는 돌려줍니다

Unused memory goes back

Android가 쉬는 동안 비어 있는 메모리는 바로 Windows로 돌아갑니다. 정해 둔 상한이 없습니다.

While Android rests, its free memory goes straight back to Windows. There is no fixed cap.

  • 페이지 반환Free page reporting
  • Doze 대기Doze when idle
  • 선택형 동결Opt-in freeze

ARM 앱도 그대로

ARM apps too

x86 판이 있으면 그것을, 없을 때만 ARM 판을 번역해 실행합니다. 오픈 소스 번역기가 기본입니다.

The x86 build runs when there is one. Only ARM-only apps go through translation, with an open source translator by default.

  • x86 우선 실행x86 first
  • 기본 번역기Default translator
  • 번역기 교체Swap the translator

장치는 HAL 단위로 PC에

Devices live on the host

카메라, 오디오, 코덱은 HAL 서비스로 PC에서 돌고, Android는 시스템 호출을 넘기지 않습니다.

Camera, audio and codecs run on the PC as HAL services. Android never forwards a system call.

  • RPC Binder
  • 호스트 코덱Host codecs
  • 카메라와 오디오Camera and audio

끌어 놓고, 붙여 넣고

Drag, drop and paste

파일을 창에 끌어 놓고, 클립보드를 함께 씁니다. 가운데 공을 직접 끌어 보세요.

Drop files on a window and share the clipboard. Try dragging the ball in the middle.

  • 파일 끌어 놓기File drag and drop
  • 클립보드 공유Shared clipboard
  • APK 설치 관리자APK Installer

기다림 없이 바로

Opens without the wait

마지막 창을 닫아도 Android는 꺼지지 않고 Doze로 쉽니다. 다음 앱은 부팅을 기다리지 않습니다.

Closing the last window puts Android into Doze instead of shutting it down, so the next app opens without a boot.

  • Doze 기본 대기Doze by default
  • 알림 전달Notifications
  • 바탕 화면 위젯Desktop widgets

같은 Android, 세 가지 호스트

One Android, three hosts

Windows가 먼저이고, 프로토콜과 게스트는 Linux와 macOS에서도 같습니다.

Windows comes first. The protocol and the guest are the same on Linux and macOS.

  • Windows 11
  • Linux (개발 중)Linux (in progress)
  • macOS (개발 중)macOS (in progress)

상한 없이,
필요한 만큼만

No fixed cap.
Only what it needs.

VM, 창 관리자, 렌더러, 앱 창이 각자 필요한 만큼만 씁니다.

The VM, the window manager, the renderer and each app window take only what they need.

Open source, end to end

Published under Apache-2.0. No Microsoft WSA binary and no Google apps are shipped.

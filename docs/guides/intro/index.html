      Desktop Subsystem for Android™ (DSA)

      Each Android app becomes a real desktop window. Android keeps its own kernel.Android 앱이 하나씩 진짜 데스크톱 창이 됩니다. Android는 자기 커널 위에서 그대로 돕니다.

      DSA runs Android as a complete system in a dedicated virtual machine, and hands each of its tasks to the host as a native window. Nothing in Android is emulated or translated. The host supplies only what a desktop owns: windows, input, and devices.DSA는 Android를 전용 가상 머신에서 온전한 시스템으로 실행하고, 그 안의 작업 하나하나를 호스트의 네이티브 창으로 넘깁니다. Android의 어떤 부분도 흉내 내거나 번역하지 않습니다. 호스트는 데스크톱이 원래 가진 것만 내줍니다. 창, 입력, 장치입니다.

      Left: Android, running on its own. Right: your desktop. The windows below are movable, focusable and closable, by pointer or keyboard (arrow keys on a title bar move it, Delete closes it).왼쪽은 혼자 돌아가는 Android, 오른쪽은 데스크톱입니다. 아래 창은 마우스로도 키보드로도 옮기고, 앞으로 가져오고, 닫을 수 있습니다. 제목 표시줄에서 화살표 키로 옮기고 Delete로 닫습니다.

      android / own system

      Android runs whole, in its own VM.Android는 전용 VM에서 통째로 돕니다.

      Android runs in a dedicated lightweight VM on a kernel that DSA builds and ships, with binder built in. The kernel, ART and the framework are Android's own. No system call is translated, the user's WSL setup is never touched, and no user has to build or replace a kernel.Android는 DSA가 직접 빌드해 함께 배포하는 커널 위, 전용 경량 VM에서 실행됩니다. binder는 커널에 들어 있습니다. 커널과 ART, 프레임워크는 모두 Android 본래의 것입니다. 시스템 호출을 번역하지 않고, 사용자의 WSL 설정은 건드리지 않으며, 사용자가 커널을 빌드하거나 바꿀 일도 없습니다.

      The consequence: apps meet the Android they were written for, and the host stays the host.그래서 앱은 자기가 만들어진 그 Android를 만나고, 호스트는 호스트로 남습니다.

      android / one task, one window

      One task, one native window.작업 하나에 네이티브 창 하나.

      There is no phone frame showing the whole Android screen. Each Android task gets its own host window, with its own taskbar button, Alt+Tab entry, Start menu entry and notifications. A custom hwcomposer hands each task's layers to the host, and frames go from the GPU to the window without a copy through the CPU.Android 화면 전체를 담는 휴대폰 틀은 없습니다. Android 작업마다 호스트 창이 따로 생기고, 작업 표시줄 단추, Alt+Tab 항목, 시작 메뉴 항목, 알림도 따로 갖습니다. 전용 hwcomposer가 작업별 레이어를 호스트에 넘기고, 프레임은 CPU를 거쳐 복사되지 않고 GPU에서 곧장 창으로 갑니다.

      The host is the shell. Android carries no launcher, no status bar and no keyboard app; text input comes from the host's own input method. The windows on this page behave the same way: move one, bring it forward, close it.셸은 호스트입니다. Android 안에는 런처도, 상태 표시줄도, 키보드 앱도 없고, 글자 입력은 호스트의 입력기가 맡습니다. 이 페이지의 창도 똑같이 움직입니다. 옮기고, 앞으로 가져오고, 닫아 보십시오.

      android / the HAL boundary

      Devices cross at the HAL, nowhere else.장치는 HAL에서만 경계를 넘습니다.

      The dashed line beside this page is the hardware abstraction layer. Everything above it stays in Android. The host lends its devices across it as HAL services over RPC Binder, so Android talks to a camera or a speaker the way it always does, and the host decides what is lent. OpenGL ES runs on ANGLE; Vulkan is remoted to the host GPU.페이지 옆의 점선이 하드웨어 추상화 계층(HAL)입니다. 그 위의 모든 것은 Android 안에 남습니다. 호스트는 RPC Binder 위의 HAL 서비스로 장치를 그 너머에 빌려줍니다. Android는 카메라나 스피커를 늘 하던 방식대로 쓰고, 무엇을 빌려줄지는 호스트가 정합니다. OpenGL ES는 ANGLE 위에서, Vulkan은 호스트 GPU로 원격 실행됩니다.

      Control messages have one definition, and the codecs for Rust, Java and C++ are generated from it. Every connection checks the protocol version, the schema hash and a per-boot secret. Lend a device:제어 메시지의 정의는 하나이고, Rust, Java, C++ 코덱은 모두 그 정의에서 생성됩니다. 연결마다 프로토콜 버전, 스키마 해시, 부팅마다 바뀌는 비밀 값을 확인합니다. 장치를 빌려줘 보십시오.

      android / idle and memory

      No window open means Doze, and memory goes back.열린 창이 없으면 Doze, 메모리는 호스트로.

      When no Android window is shown, Android enters Doze, as a phone does in a pocket: notifications still arrive and the CPU rests. Memory that Android frees is reported and returned to the host while it runs, not only when it stops. Freezing the guest is opt-in, never the default.보이는 Android 창이 없으면 Android는 주머니 속 휴대폰처럼 Doze에 들어갑니다. 알림은 그대로 오고 CPU는 쉽니다. Android가 비운 메모리는 멈출 때가 아니라 돌아가는 동안 계속 호스트에 알려지고 돌려집니다. 게스트를 얼리는 것은 사용자가 고를 때만이고, 기본값이 아닙니다.

      Close the windows on this page and watch the rail: tasks leave, the memory figure falls, and Android dozes.이 페이지의 창을 닫으면서 왼쪽을 보십시오. 작업이 빠지고, 메모리 수치가 내려가고, Android가 Doze에 듭니다.

      android / three hosts

      One guest, three hosts.게스트 하나, 호스트 셋.

      The protocol, the guest and the host core name no operating system. Each host adds only its VM, its transport and its window system, so the Android that runs is the same on all three.프로토콜, 게스트, 호스트 코어에는 특정 운영체제가 들어 있지 않습니다. 호스트마다 VM, 전송 수단, 창 시스템만 더하므로 세 호스트 모두에서 같은 Android가 돕니다.

      android / open source

      Built from parts anyone may carry on.누구든 이어 갈 수 있는 부품으로 만듭니다.

      Microsoft ended the Windows Subsystem for Android on March 5, 2025, and the apps people ran with it lost their place on the desktop. DSA covers what it did and goes further, on Apache-2.0 code with no proprietary binaries. No app store and no Google Play services ship with DSA; installing them stays the user's choice.Microsoft는 2025년 3월 5일 Windows Subsystem for Android 지원을 끝냈고, 그 위에서 쓰던 앱은 데스크톱에서 자리를 잃었습니다. DSA는 그때 되던 일을 모두 해내고 그 이상을 목표로 하며, 독점 바이너리 없이 Apache-2.0 코드로 만듭니다. 앱 스토어나 Google Play 서비스는 함께 배포하지 않습니다. 설치는 사용자가 정합니다.

      Development is public: issues, pull requests, and a test for every specified behaviour.개발은 공개로 진행합니다. 이슈와 풀 리퀘스트가 열려 있고, 정해 둔 동작마다 테스트가 있습니다.

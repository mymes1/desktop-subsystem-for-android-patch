DSA
Desktop Subsystem for Android™

Android, sovereign.
Its apps, free. 스스로 다스리는 Android,
자유로운 앱.

DSA does not imitate a phone. It gives Android a machine of its own: its own virtual machine, its own kernel, its own complete system. Then each app steps out of it and becomes a real window on your desktop. DSA는 휴대폰을 흉내 내지 않습니다. Android에게 자기만의 기계를 줍니다. 자기 가상 머신, 자기 커널, 온전한 자기 시스템입니다. 그리고 앱 하나하나가 그 안에서 걸어 나와 데스크톱의 진짜 창이 됩니다.

Close every window and Android dozes while its unused memory flows back to the host. 측정이 아닌 그림입니다. 왼쪽은 자기 커널을 가진 Android VM, 선은 HAL 경계, 오른쪽은 데스크톱입니다. 창을 모두 닫으면 Android가 Doze에 들고, 쓰지 않는 메모리가 호스트로 흘러 돌아갑니다.

01

A whole system, governing itself.스스로를 다스리는 온전한 시스템.

Android runs in a dedicated lightweight VM with a kernel DSA builds and ships. Its kernel, its runtime and its framework stay Android's own. Nothing is translated, nothing is faked at the system call level, and nothing depends on the user's WSL or on a kernel the user has to build.Android는 DSA가 직접 빌드해 함께 제공하는 커널 위에서, 전용 경량 VM으로 실행됩니다. 커널, 런타임, 프레임워크는 그대로 Android의 것입니다. 시스템 호출을 번역하거나 흉내 내지 않고, 사용자의 WSL이나 사용자가 직접 빌드할 커널에 기대지 않습니다.

02

No phone frame. Windows.휴대폰 틀이 아니라, 창.

Every Android task is its own native window, with its own taskbar button, Alt+Tab entry, Start menu entry and notifications. A custom hwcomposer hands each task's layers to the host, and frames travel GPU to window without passing through the CPU. The host is the shell: there is no launcher, no status bar and no keyboard app inside Android.Android 작업 하나하나가 자기 작업 표시줄 단추, Alt+Tab 항목, 시작 메뉴 항목, 알림을 가진 네이티브 창입니다. 전용 hwcomposer가 작업마다 레이어를 호스트로 넘기고, 프레임은 CPU를 거치지 않고 GPU에서 창으로 갑니다. 셸은 호스트입니다. Android 안에는 런처도, 상태 표시줄도, 키보드 앱도 없습니다.

03

The border is the HAL. The treaty is one protocol.국경은 HAL, 조약은 하나의 프로토콜.

Android keeps its sovereignty; the host lends its devices. GPU, audio, camera, sensors and location cross at the hardware abstraction layer, as HAL services over RPC Binder. Control messages follow one definition, with codecs generated for Rust, Java and C++. Every connection checks the protocol version, the schema hash and a per-boot secret.Android는 주권을 지키고, 호스트는 장치를 빌려줍니다. GPU, 오디오, 카메라, 센서, 위치는 하드웨어 추상화 계층에서 RPC Binder 위의 HAL 서비스로 경계를 넘습니다. 제어 메시지는 하나의 정의를 따르고, Rust, Java, C++ 코덱은 그 정의에서 생성됩니다. 모든 연결은 프로토콜 버전, 스키마 해시, 부팅마다 바뀌는 비밀을 확인합니다.

04

Memory comes home.메모리는 집으로 돌아옵니다.

When no window is shown, Android enters Doze, as a phone in a pocket does: notifications still arrive, the CPU rests. Memory Android frees is reported and returned to the host continuously while it runs, not only when it stops. Freezing is a choice, never the default.보이는 창이 없으면 Android는 주머니 속 휴대폰처럼 Doze에 듭니다. 알림은 계속 오고 CPU는 쉽니다. Android가 비운 메모리는 멈출 때만이 아니라 실행 중에도 계속 호스트로 돌아갑니다. 얼리기는 선택이며, 기본값이 아닙니다.

05

One guest. Three homes.하나의 게스트, 세 개의 집.

The protocol, the guest and the host core name no operating system. Each host adds only its VM, its transport and its window system.프로토콜, 게스트, 호스트 코어는 어떤 운영체제도 지목하지 않습니다. 호스트마다 VM, 전송, 창 시스템만 더합니다.

06

Open, so it can outlive any one owner.열려 있기에, 누구 하나보다 오래갑니다.

Microsoft ended the Windows Subsystem for Android on March 5, 2025. DSA rebuilds that experience on parts anyone may carry on: Apache-2.0, no proprietary binaries, and no app store or Google Play services shipped, which stay the user's choice. Work happens in the open on the develop branch: issues, pull requests, and tests for every behaviour.Microsoft는 2025년 3월 5일 Windows Subsystem for Android를 끝냈습니다. DSA는 그 경험을 누구나 이어 갈 수 있는 부품으로 다시 짓습니다. Apache-2.0이고, 독점 바이너리가 없으며, 앱 스토어나 Google Play 서비스는 함께 제공하지 않고 사용자의 선택으로 남깁니다. 작업은 develop 브랜치에서 공개로 이루어집니다. 이슈, 풀 리퀘스트, 모든 동작에 대한 테스트로요.

# 메모리와 유휴 동작

Desktop Subsystem for Android™(DSA)는 쉬고 있는 Android가 컴퓨터에 부담을 거의 주지 않도록, 그리고
Android가 더 쓰지 않는 메모리가 컴퓨터로 돌아가도록 만들어졌습니다.

## 유휴 상태, Doze

모든 Android 창을 닫거나 최소화한 지 30초가 지나면, 주머니 속 휴대폰처럼 Android 화면이 꺼지고 Doze에
들어갑니다. 알림, 알람, 위젯은 Doze의 짧은 유지 관리 구간에 계속 동작하고, 그 사이 CPU는 쉽니다.
이때 `dsa status`는 `Dozing`이라고 알려 줍니다. Android 창을 하나라도 보이면 바로 깨어납니다.

Android는 컴퓨터의 절전도 따릅니다. 컴퓨터가 잠들기 전에 상태를 저장하고, 깨어나면 시계를 맞춥니다.
배터리도 컴퓨터의 배터리를 따릅니다.

## 얼리기 (기본값 꺼짐)

얼리기는 Android의 프로세스를 아예 멈추므로 알림, 알람, 위젯 갱신도 멈춥니다. 그래서 기본으로는 절대
얼리지 않습니다.

- `dsa freeze`는 지금 얼립니다.
- DSA 설정 **고급** 페이지의 "유휴 시 얼리기"나 `dsa settings set freeze on`은 Doze 30분 뒤에 얼립니다.
- 창을 보이거나 창에 입력하면 다시 움직입니다.

## 메모리는 계속 돌아갑니다

- VM의 메모리는 Android가 처음 건드릴 때에만 컴퓨터에서 가져오고, Android가 비운 페이지는 멈출 때만이 아니라
  실행 중에도 계속 알려서 컴퓨터로 돌려줍니다.
- 1분 동안 어떤 앱도 쓰지 않으면 Android가 오래 쓰지 않은 페이지를 압축 메모리로 옮기고 깨끗한 캐시를 버려서,
  그 메모리를 돌려줄 수 있게 합니다. 창이 하나도 없는 채로 잠들면 캐시된 앱을 끝냅니다.
- 최소화한 창의 프로그램과, 30초 동안 보이는 창이 없을 때의 창 관리자는 쓰지 않는 메모리를 내놓습니다.

정해 둘 고정 메모리 상한은 없습니다. 메모리 한도는 기본으로 자동입니다. DSA 설정의 **메모리** 페이지나
`dsa settings set memory-limit 4g`로 정할 수 있고, `auto`로 되돌립니다.

## 확인하기

`dsa memory`는 호스트에서 Android가 쓰는 메모리(VM, 창 관리자, 앱 창마다)와 Android 안의 메모리(사용 중,
캐시, 앱 메모리, 압축 스왑, 가장 큰 프로세스)를 보여 줍니다. DSA 설정의 **메모리** 페이지도 같은 내용을
보여 줍니다.

## 목표 (아직 달성 전)

단순한 앱 하나를 연 상태에서 DSA의 모든 프로세스가 쓰는 private 메모리 합을 단기 400 MiB 이하, 최종
250 MiB 이하로 하고, 앱을 하나 더 열 때 늘어나는 몫을 80 MiB 이하로 하는 것이 목표입니다. 이 숫자는 목표이며,
측정하며 개선하고 있습니다.

# DSA 사용 안내서

이 안내서는 Desktop Subsystem for Android™(DSA)를 쓰는 방법을 설명합니다. 지금 무엇을 하는지,
어떻게 설치하는지, 문제가 생기면 무엇을 하면 되는지를 다룹니다. 내용은 현재 미리보기 버전 기준입니다.
끝나지 않은 기능은 상태를 함께 적었습니다.

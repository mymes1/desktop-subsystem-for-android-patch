# The Vulkan CTS cases every graphics change must keep passing through the remoting path.
#
# One pattern per line; `*` matches any run of characters. Every pattern must match at least
# one case of the dEQP-VK mustpass list shipped with the pinned Android CTS (verify.py checks
# this), so a renamed case is caught instead of silently running nothing.
#
# The subset covers what the remoting path itself carries: device and instance queries,
# memory allocation and host-visible mapping, shader creation, a draw into an image read back
# by the guest, fences and semaphores, and the Android window surface a task window uses.
